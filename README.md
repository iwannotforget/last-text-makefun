A dying phone's last text, entered in make.fun's Last Text at One Percent.
The whole entry is one line of at most 200 characters; `main.ts` (Node 22,
standard library only) writes it to `/output/entry.txt`:

> At 1%, dying as I lived: ignoring your software updates since 2022.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts && cat out/entry.txt
```
